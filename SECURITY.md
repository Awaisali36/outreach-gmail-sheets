# 🔒 Security Policy

## Supported Versions
We release patches for security vulnerabilities only for the following versions:

| Version | Supported |
|---------|-----------|
| main    | ✅        |

## Reporting a Vulnerability
If you discover a security vulnerability, please help us by reporting it responsibly:

- **Email**: awaisstudent1687@gmail.com
- **GitHub Issues**: Please **do not** open a public issue for security-related problems.  
- Provide as much detail as possible (steps to reproduce, potential impact, etc.).  

We will review the report, confirm the issue, and provide updates as we work on a fix.

## Disclosure Policy
- You will receive an acknowledgment within **48 hours**.  
- We aim to provide a fix within **7–14 days** depending on severity.  
- After resolution, we will publish details of the vulnerability and its fix.
